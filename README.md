
# 📊 Campus Cafe Sales Dashboard

An interactive **Campus Cafe Sales Dashboard** developed using **Tableau** to analyze sales performance, monthly sales trends, product categories, best-selling items, locations, and customer purchasing patterns.

## 🎯 Project Objective

The objective of this project is to transform Campus Cafe sales data into an interactive Tableau dashboard that provides meaningful insights through data visualization.

## 🛠️ Tools & Technologies

- Tableau Desktop / Tableau Public
- Excel / CSV Dataset
- Data Visualization
- Dashboarding

## 📈 Dashboard Features

- Total Sales KPI
- Monthly Sales Trend
- Sales by Category
- Top 10 Best-Selling Items
- Sales by Location
- Regional Filters
- Frequency vs Monetary Scatter Plot
- Interactive Filters
- Cluster Analysis

## 🔍 Key Insights

1. The dashboard provides an overview of total cafe sales.
2. Monthly trends help analyze changes in sales over time.
3. Category-wise analysis compares the performance of different cafe categories.
4. The Top 10 visualization highlights the best-selling products.
5. Location and regional analysis helps understand sales distribution.
6. The scatter plot shows the relationship between customer purchase frequency and monetary value.
